# lab6 — рабочие материалы

Приложение на основе lab5. BASIC-аутентификация защищает все URL приложения. Доступ разрешён роли order-user. Учебный пользователь student имеет эту роль; guest используется для проверки запрета доступа (403).

Отдельный Tomcat: local/lab6-server (подготовка описана в README корня). HTTP: http://localhost:8086/lab6/; HTTPS: https://localhost:8446/lab6/.
Конфигурации, учебные пользователи, пароли и хранилище сертификата опубликованы в config/. Данные для входа и ожидаемые ответы сервера: [ACCESS.md](ACCESS.md). Для подготовки отдельного экземпляра сервера используйте scripts/prepare_lab6.py из корня репозитория.
Сертификат RSA 2048, SAN localhost/127.0.0.1, хранилище PKCS12. Публичный сертификат: localhost.crt. Системное хранилище доверия не изменялось.

Сборка install javadoc:javadoc: BUILD SUCCESS (build.log). WAR: target/lab6.war. Javadoc: target/site/apidocs/index.html.
Проверки HTTPS с включённой проверкой сертификата: checks.txt. Отсутствующий/неверный пароль — 401, неподходящая роль — 403, разрешённая роль — 200; расчёт POST проверен.
Браузер может показывать предупреждение о самоподписанном сертификате. Автоматический обход предупреждения и ввод учётных данных в диалог браузера не выполнялись.
Браузерный скриншот аутентифицированного приложения сохранён пользователем.
