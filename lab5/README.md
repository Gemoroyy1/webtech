# lab5 — рабочие материалы

JSP-приложение расчёта заказа: index.jsp формирует POST-запрос, calculate.jsp обрабатывает его с помощью Java-класса OrderCalculator и выводит результат. При ошибке выполняется forward в WEB-INF/error.jsp с HTTP 400.
