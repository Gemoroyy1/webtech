# lab7 — рабочие материалы

index.jsp — форма имени и цвета. save.jsp сохраняет значения в Cookie на 7 дней и обновляет счётчик, предыдущую и последнюю даты обращений в сессии, затем перенаправляет на display.jsp.
display.jsp читает Cookie из нового запроса и показывает переменные сессии на выбранном фоне.
Счётчик учитывает отправки формы. Обновление страницы результата не увеличивает счётчик.
Время выводится в UTC. Цвет проверяется по разрешённому списку, имя экранируется для HTML.
Сборка: BUILD SUCCESS (build.log). WAR: target/lab7.war.
Проверки: verify.py, checks.txt. Скриншоты: screenshots/.
Адрес: http://127.0.0.1:8081/lab7/
